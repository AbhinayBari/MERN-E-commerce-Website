# Full Stack E-Commerce Web Application

A modern full-stack e-commerce web application built using the MERN Stack with secure authentication, product management, shopping cart, and order functionality.

## 🚀 Features

* User Authentication & Authorization
* Product Listing & Details Page
* Shopping Cart Functionality
* Order Management
* Responsive UI Design
* REST API Integration
* MongoDB Database Connectivity

## 🛠 Tech Stack

### Frontend

* React.js
* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## 📦 Installation

### Clone the repository

```bash
git clone <https://github.com/AbhinayBari/MERN-E-commerce-Website.git>
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

## 🔑 Environment Variables

Create a `.env` file in the backend folder and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
